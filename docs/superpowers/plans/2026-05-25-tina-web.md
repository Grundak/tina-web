# Tina Web Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a classy BDSM-editorial Next.js portfolio site for Tina with an age gate, home page, gallery page, links page, and animated Spotlight Drawer navigation.

**Architecture:** Use Next.js App Router for route pages and reusable client components where interactivity is required. Keep gallery and social links in data files so placeholders can be replaced without touching page layout. Use Vitest for small helper tests and `next build` for production verification.

**Tech Stack:** Next.js, React, TypeScript, CSS modules/global CSS, Vitest, Vercel static deployment defaults.
